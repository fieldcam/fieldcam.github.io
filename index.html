STEP-BY-STEP TUTORIALS

Category-based guide for first-time users

  1. Open FieldCam and allow Camera, Location, and Audio when prompted.
  2. If "Tap to fix" appears, tap it and grant missing permissions.
  3. Confirm preview is visible and permission warning is cleared.
  1. Go to Settings and open Stamp Template Manager.
  2. Select a template (Smart Field Pro recommended for default workflow).
  3. Adjust metadata fields, text style, and watermark mode as needed.
  1. Open Settings and go to Sync Settings.
  2. Choose Google Drive or FTP and configure account/credentials.
  3. Select categories and sync mode, then run a test sync.
  1. Open Gallery and select required photo/video files.
  2. Choose export format (PDF, CSV, ZIP, etc. as available).
  3. Share via your workflow or verify cloud sync completion.

GOOGLE OAUTH AND DATA USE

Transparent permission and user-data explanation

Permission / Data Why FieldCam requests it User control
Camera Capture photo and video evidence. Can be denied or changed in Android app settings.
Location Attach GPS coordinates and address metadata. Can be granted only while using the app.
Microphone Audio track for videos. Can be disabled by denying microphone permission.
Storage / Photos and Videos Read and manage captured media for export and sync. Can be adjusted in system permission screen.
Google OAuth (Drive sync) Upload user-selected FieldCam media to user Google Drive. User can disconnect account and revoke access in Google account settings.

Google OAuth quick reference

  • FieldCam uses Google sign-in only to enable Drive sync.
  • Drive access is used for FieldCam media backup/sync workflows.
  • This homepage and the privacy policy are publicly visible without login.
  • Privacy policy: https://fieldcam.in/privacy.html
